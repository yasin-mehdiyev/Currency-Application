# Currency-Application

This task is related to create a SPA to make it comfortable for users to manage exchanges rates. I have used many Frontend technologies in this task. Which that These are noted in the following:

React, React Hooks (Functional Components), as state managment Redux Toolkit, Typescript, Style-Components, Material UI, Reactstrap, Axios, SweetAlert.js,React-Router version 6, Code splitting(Suspense, Lazy loading) etc.
